# Agnes Video Director — 动作设计 & 电影感提示词导演

让 agnes 视频出片"能看"且"好看"的提示词设计技能。只设计提示词文本并编排 scenes.json；实际生成走 agnes-media 的 `generate_video.py`（本 skill 的 scripts/ 已随附）。

核心前提：AI 视频模型没有记忆、单个 prompt 塞太多动作必然失败。所以一切规则围绕 **"每段只做一件事，段与段之间有因果，外观被锁死，画面有反馈"**。

---

## 一、四条铁律（保证"能看"，缺一不可）

设计任何片段前先搭骨架：

1. **时序拆段**：agnes 单段硬上限 **12 秒**。每段只负责**一组主要动作**，prompt 内用时间戳显式标出（`0-4s ... 4-8s ... 8-12s`）。禁止一个 prompt 塞十几个同时发生的动作。超过 12 秒 → 拆成多段 scenes.json 拼接。
2. **动作因果链**：相邻动作必须是物理因果关系——"对手前冲 → 主角借惯性侧身"、"击中腹部 → 对手前倾 → 下一段才可能被抓肩"。每个动作都要能回答"上一个动作给了它什么条件"。孤立动作 = 瞬移/穿模的根源。
3. **环境反馈**：每段至少写一处环境反馈（尘土飞扬、火星迸溅、竹叶炸开、水面涟漪、地面裂纹、碎屑飞溅）。这不是装饰——它告诉模型力量来自哪里，打击感由此落地。
4. **资产锁定（角色护照）**：每段 prompt 开头用独立段落声明人物脸/发型/服装/武器/体态**全程不变**。多角色场景必须分别说明每个角色是谁。跨场景一致性的核心做法：给主角建一张"护照"文本块（见 `references/asset-passport.md`），**逐字复制**进每个场景的 prompt。

---

## 二、进阶规则（保证"好看"）

1. **音效独立成层**：单独写音效段。agnes 默认生成音频；无配乐需求时显式写 "no music, only ambient sound"。音效覆盖三层：力量（碰撞、拔刀）、材质（雨声、竹叶、碎石）、生物/呼吸。
2. **动作结果允许失败**：打击 ≠ 命中即胜。刀被弹开、反作用力震退、刀刃卷曲——物理一致的挫败比全程碾压更可信。
3. **关键动作轨迹拆解**：不写结果、写轨迹——"跃起 → 双手高举 → 竖向重劈 → 剑刃正中对方刀背"，四步链条让模型逐帧可执行。
4. **微慢动作给具体时长**："约 0.2-0.3 秒微慢动作后立刻恢复正常速度"，每段最多一次。
5. **结尾铺垫下一轮**：余韵段不止定格——转身、收刀、目光锁定，给下一段留钩子。
6. **群体分层写**：多人场景交代数量与行为顺序（"6 名影卫齐转身，其中 2 名先扑出"），镜头明确拍出顺序；面孔互不相同、禁止与主角相似。
7. **风格开关前置**：一镜到底、手持纪实质感、慢动作节奏等整体声明放 prompt 最前部，只声明一次。

## 三、六段式提示词结构（组装顺序）

按此顺序组装成一段 12 秒的 agnes prompt（英文），缺段可省但顺序不变：

```
[STYLE]        # 风格开关：single continuous shot / handheld / epic slow motion ...
[PASSPORT]     # 角色护照：外观锁定 + 参考图映射（如有）
[SCENE]        # 场景：环境、光线、色调、氛围粒子（雨/雾/尘）
[TIME-CODES]   # 时序段：0-4s / 4-8s / 8-12s 各一组主动作 + 因果 + 环境反馈 + 运镜
[SOUND]        # 音效层：no music, only ...（雨声、金属碰撞声）
[CONSTRAINTS]  # 负向词条 + 技术参数（16:9 720P 等，负向见 references/negative-prompt.md）
```

运镜语言必须**有物理动机**：不要写 "dynamic camera"，要写相机**为什么**动（"camera dives in as the blade strikes", "orbit follows the opponent's lunge"）。相机锁在主体上时相对运动为零，主体最清晰。词库见 `references/camera-lexicon.md`。

## 四、三拍式节奏骨架（多段编排）

一个动作片段（2-6 段）按三拍分配，再微调：

| 拍 | 占比 | 内容 |
|---|---|---|
| 蓄力 | ~30% | 对峙、逼近、第一次试探交锋，镜头缓慢、环绕/推近 |
| 爆发 | ~50% | 主交锋：连续因果动作链，打击最密集，贴身跟拍/手持震动 |
| 余韵 | ~20% | 收尾定帧：胜负分明、尘埃落定、镜头缓推，给下一段留钩子 |

多段输出样式二选一（同一片段不混用）：
- **时间戳式**（`0:00-0:04`）：快节奏对打、追车战，镜头切换频繁。
- **镜头命名式**（`Shot 01 — Approach`）：大场面、景别大幅跳转，每镜一个动词性命名。

## 五、工作流程

1. **收集输入**（缺项一次性问全）：主题/题材、总时长（agnes 每段 ≤12s，整段按 12 的倍数或自定）、角色几个+外观+武器、有无参考图、环境材质（决定反馈词汇）、音效偏好（默认不要音乐）、旁白文案（中文，可选，走 TTS）。
2. **搭骨架**：按三拍式分配段数 → 输出阶段表（段 id / 时长 / 拍 / 主动作 / 因果衔接 / 环境反馈）给用户确认。
3. **写 prompt**：按六段式组装，护照逐字复制，负向词条挑 3-5 条。
4. **QA 核对**（交付前自查）：
   - [ ] 每段 ≤ 一组主动作，时长 ≤ 12s
   - [ ] 相邻段能说出因果衔接（"因为 A 所以 B"）
   - [ ] 每段 ≥ 1 处环境反馈
   - [ ] 开头有护照段；多角色参考图映射明确
   - [ ] 运镜有变化且服务于动作；无 "dynamic camera" 式空泛运镜
   - [ ] 关键一击写了轨迹拆解；微慢动作给了具体时长（≤1 次）
   - [ ] 有音效层且默认 "no music"
   - [ ] 有负向词条（no text / no watermark / no extra characters 等）
   - [ ] 结尾有下一轮铺垫；输出样式全文统一

## 六、落地到 agnes 管线

生成 3 段 36 秒的 demo 全流程（参考 `/data/home/videospace/director_demo/`）：

```bash
# 1. scenes.json 每段 id/seconds/zh/prompt（+ 可选 first_frame/images）
python3 scripts/generate_video.py --root DIR   # 写 segments/ + ALL_DONE
python3 scripts/gen_tts_pause.py               # 写 tts_fit/*.m4a（需先有 segments）
python3 scripts/stitch.py                      # 字幕+混音+xfade → 最终 mp4
```

一致性增强（超出纯 prompt 的手段）：
- **img2img 出关键帧 → keyframe 模式**：先 `scripts/gen_image.py --image 护照图 --prompt "NEW COMPOSITION: ..."` 生成目标姿态首帧，再让场景用 `first_frame` 锁定构图（agnes 已验证 keyframe 模式）。
- **reference 模式**：跨场景角色/风格一致时，把护照图放入 `images` 数组（`Use <Picture 1> as character reference`）。

边界：只做提示词设计与编排，不直接调生成接口以外的任何平台；长于 12 秒一律拆段，不试图超限提交。
