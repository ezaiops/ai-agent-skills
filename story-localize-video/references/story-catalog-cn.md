# 中国公版作品 · 现代化改编素材库（华洲宇宙专用）

筛选标准：**作者逝世超过 50 年（中国大陆公版口径）+ 国内认知度高 + 现代化空间大 + 流量定位明确**。
与 `story-catalog.md`（外国篇目）互补：中国篇目的优势是**零符号转换成本**——人物关系（熟人社会/编制/彩礼/同学会）、价值观（面子/孝道/人情）、场景（县城/单位/小镇）本体就在中国语境里，观众无出戏感；同时没有「译本禁区」问题。代价是**检索词认知度参差**：国民级名篇自带流量，冷门篇目要靠自己造钩子。

> 版权提示：本清单只做「候选」判定。每篇正式开工前仍须走 `00_copyright.md` 逐篇核查（含译本/影视改编专属表达/商标/形象比对），以下「禁忌」列是预检结论。

|---|---|---|---|
| **《孔乙己》** 鲁迅 (1936) | 死要面子的读书人守着"长衫"却不肯谋生，被时代甩下 → 落魄 | 梗已经在网上活了：「脱下长衫的孔乙己」= 大学生/小镇做题家不肯放下学历执念。现代版可做**毕业即失业·高学历低就**群像 | 打工人共鸣爆款 / 话题号，第一推荐 |
| **《断魂枪》** 老舍 (1966) | 年轻时一身绝技（镖局枪王），时代变了自己一身功夫没人认 → "不传！" | 非遗/老手艺师傅 vs 直播带货时代：一身绝活,徒弟全去直播卖货,无人认功夫。末句"不传！"是天然结尾字幕 | 温情 + 时代落幕 / 中青年双共鸣 |
| **《卖油郎独占花魁》** 冯梦龙《醒世恒言》(1646) | 最卑微的小贩,不趁人之危,以真纯赢下花魁的心（真诚战胜势利） | 外卖骑手 × 顶流主播：全城都在讨好她,只有他最笨最真。逆袭内核不变 | 甜虐反转 / 逆袭向 |
| **《画皮》** 蒲松龄《聊斋志异》(1715) | 美艳皮囊下藏着恶,人只看皮 → 真相戳破 | 网红滤镜/人设崩塌：线上是完美人设,线下是另一张脸,直播突然翻车。**志怪必须人为作祟化**（"皮"= 整容/滤镜/人设，不出现鬼怪实体） | 都市惊悚 + 爽感反转 |
| **《崂山道士》** 蒲松龄 (1715) | 投机学"穿墙术",法术失灵一头撞在墙上 | "速成班"割韭菜：交钱学"人生捷径秘法",大师一跑,学员头撞南墙。结尾撞墙是现成笑点 | 喜剧讽刺 / 反知识付费 |
| **《匡超人》** 吴敬梓《儒林外史》(1754) | 靠造假抄书出名 → 成为名流后彻底黑心,连恩人都坑 | 社交名媛/知识网红造假人设、卖课割韭菜、红了就翻脸。**逐名利而忘恩义**的完整弧线 | 讽刺短剧 / 网红翻车 |
| **《杜十娘怒沉百宝箱》** 冯梦龙 (1646) | 攒下毕生财宝托付真爱,对方为钱转卖她 → 当众怒沉百宝箱,一生成空 | 凤凰男攀上富家姐姐/拿彩礼高攀,面对"更好的买卖"立刻变了脸 → 末句反转：她把所有东西当众丢进江里。**避开戏曲/影视专属构图**（投江携箱名场面），自造新动作 | 反转爽感 + 话题度（彩礼/凤凰男） |

## 鲁迅专栏（A 级改编源，认知度最高）

鲁迅（1881–1936），逝世 50 年以上，**公版**。短篇极具"反转/讽刺/共鸣"基因，且现代热搜梗已自带流量（孔乙己长衫、祥林嫂式倾诉）。改编只保留人物处境与结构公式，绝不搬民国服饰/场景/台词（那属于旧时代外壳）。

| 篇目 | 内核（不可变） | 现代化方向建议 | 流量定位 |
|---|---|---|---|
| **《孔乙己》**（A+） | 守着"长衫"身份不肯放下身段，被时代甩下，最终消失 | 脱不下学历/面子的年轻人：211 毕业宁做"高薪文员"不愿做"丢脸活"，网上梗"脱下长衫"直接借热度 | 打工人共鸣爆款 / 第一推荐 |
| **《伤逝》**（A+） | 穷小子与富家女的爱情被现实（失业/世俗）碾碎，"人必生活着，爱才有所附丽" | 一线城市租房情侣：他失业、她辞职、热恋被房租劈开 | 都市爱情现实刺痛 |
| **《祝福》**（A） | 丧夫丧子被全村嫌"不祥"，新年祝福时刻冻死 | 小镇丧偶妇女被"不祥"标签孤立，除夕夜营销号消费她 | 悲情共鸣（需升华出口） |
| **《故乡》**（A） | 童年发小 → 成年厚障壁：身份与阶层把"我们"隔开 | 县城发小 vs 一线白领：多年后同学会重逢只剩"老爷/你吃了吗"式客套 | 温情/落差刺痛 |
| **《阿Q正传》**（B） | 永远的精神胜利法——被打后说"儿子打老子" | 职场/网络里的"阿Q"：被裁却说"是我不想干了"，被骂却自我胜利 | 讽刺喜剧（需对冲） |
| **《在酒楼上》**（B） | 少年意气被现实磨平后，连"悔"都懒得有 | 中年老同学重逢：我们都成了当年最不想成为的人，干杯，谁也不提 | 中年余韵/催泪 |
| **《药》**（B，慎用） | 用烈士的血做"人血馒头"治病，群众冷漠 | "吃人血馒头"的流量消费：热点事件被营销号消费，当事人家属还在被拍 | 讽刺，但涉真实热点风险高，建议架空化 |
| **《狂人日记》**（C） | 全员"吃人"，癫狂即是清醒 | 职场/家庭"吃人"隐喻，抽象程度高，改编空间大但落地难 | 实验向 |

**鲁迅改编通用红黄线**
- 禁用民国戏：不出现长衫/辫子/咸亨酒店；姓名一律换用华洲命名库。
- 删除"批判旧社会制度"的直给，改为当代普适议题（学历焦虑/房贷/职场/婚恋），避免敏感。
- 反转为核心：鲁迅原作多"处境的持续恶化+微末希望"，短片需补一个"最后字幕反转"当情绪落点（例：孔乙己结局字幕点题"长衫穿得越久，越难脱下"）。
- 不搬鲁迅专属名句"翻译腔"，全部现代口语重写。

## 与外国篇目对比 · 选用建议

| 维度 | 中国公版 → 现代改编 | 外国公版 → 中文化改编（story-catalog.md） |
|---|---|---|
| 接受度/真实感 | ★★★★★（零符号转换） | ★★★☆（舞会→同学会每处都要"翻译"，漏一处就出戏） |
| 检索词流量 | 国民级名篇自带（孔乙己/范进/画皮）；冷门篇目为零 | ★★★★★（"莫泊桑《项链》中国版"有天然搜索词） |
| 版权干净度 | 无译本禁区 | 有译本禁区（禁抄译本句子） |
| 甄别成本 | 需逐篇甄别"已拍烂/已蹭烂"的名场面 | 需逐篇确认是否为原文 vs 影视记忆 |

**结论进 skill 的决策准则**：默认优先中国公版（接受度优先）；"蹭原著名篇检索词引流"时优先外国公版（流量优先）。
