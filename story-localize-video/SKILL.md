# 公版外国短篇 → 中文化改编 → agnes 视频全案

定位：本 skill 是**内容侧**（版权核查 + 中文化改编 + 剧本 + 分镜策划 + 文案）。生成执行（图片/视频/TTS/拼接）交给 `agnes-media`，提示词工艺交给 `agnes-video-director`。本 skill 负责把两者串成一条可复用的改编流水线，并守住版权红线。

**核心创作原则：所有故事都发生在一个我们自建·架空·免责的虚构宇宙里（阶段0），不指涉真实地点/机构/事件/人物。**

相邻 skill 分工（开始工作前先明确）：互动与文案来自本 skill；**写任何一段英文视频 prompt 前必须加载 `agnes-video-director`**，按它的六段式结构与四条铁律产出，不要在本流程里临时发明提示词格式。API 调用一律复用 `agnes-media` 的 scripts；**交付前必须加载 `story-logic-check`** 跑一遍逻辑矛盾报告（阶段 5 的 Gate 7），确认因果链自洽、无前后矛盾、内核保值、护照↔分镜交叉一致、经济/时代符号重新校准。

## 阶段 0｜虚构世界观（故事宇宙）→ `story/_universe/world-bible.md`

**所有改编故事的共同舞台**。一次性建好，之后每个故事只需引用它。内容：

| 模块 | 要求 |
|---|---|
| 舞台名 | 一个虚构国/地区名 + 若干虚构省市县镇名（见下方命名规则）。默认套餐：「华洲」× 一个虚构城市（如棠溪市），可全局更换 |
| 年代 | 平行当下 / 模糊的年代感，不写具体年份 |
| 机构 | 警方、教育、医疗、媒体**全用通用化或虚构名**（"临江市公安局"→"棠溪市局""警方"） |
| 品牌 | 商店/学校/公司/App 全部虚构命名，禁止真实品牌 |
| 人物 | 全部虚构；禁止以真实人物/名人/企业家为原型 |
| 免责声明 | 成片固定尾注："本片为虚构故事，人物与场景均为虚构，如有雷同纯属巧合" |

### 命名规则（防敏感与防攀附）
- 地名不采用真实地名及其谐音、不直接拼凑真实省份地名；
- 常用安全字库：临/澄/棠/溪/澜/屿/云/平/汀/芜/黎/安 … 例：棠溪市、澄江市、星屿区、澜川县；
- 中学叫"棠溪一中"、"澜川实验中学"，医院"市第一人民医院"→"棠溪市第一医院"；
- 审查自查：成稿后扫一遍人物名/地名/品牌名与真实存在的名称是否重名（可 `grep` 检索）。

### 世界观文件的增量维护
新故事引入新地点/机构时，同步回写 `world-bible.md`，保持宇宙一致（地图上不会长出两个同名城市）。

## 一、开始之前：收集输入（缺项一次问全）

1. **作品**：作者 + 篇名 + 是否已有原文/译本（有最好，无则给出出处由我们检索公版原文大意）。
2. **形态**：单集短片（3–6 分钟）还是分集短剧；横屏 16:9 还是竖屏 9:16（agnès 视频支持，prompt 由 ratio 控制）。
3. **视觉风格**（复用 storyclaw 风格系统）：默认可选 国风水墨 / 电影写实 / 日系动画 / 三维动画 / 赛博朋克 / 都市写实 / 喜剧漫画风。中文化 ≠ 必须古风；现代故事就走现代设定。
4. **情绪基调**：反转爽感 / 温情治愈 / 黑色幽默讽刺 / 悬疑惊悚。
5. **出片层次**：全案（核查→剧本→分镜→scenes.json→文案）还是只到某一层（如只要剧本）。
6. **目标平台**（影响审核尺度与标题写法）：抖音/快手/视频号/B站/YouTube。

默认输出一套完整全案；用户只要某层时按需裁剪。

## 二、版权核查（Gate 0，必做，不跳过）

改编前先输出一份简短的 `00_copyright.md`，逐条下结论，不能让模型默认“记得的故事”就等于可用：

| 检查 | 判定方法 |
|---|---|
| 公版判定 | 在中国大陆：**作者逝世超过 50 年**即进入公有领域。给出"作者生卒年 → 公版结论"。合作作者按最后一位作者卒年算。 |
| 译本禁区 | 原著无版权 ≠ 译本无版权。**严禁抄现有译本的句子**，也不得整段改写某个译本。改编必须从故事层面重写（换人物换场景换语言自然是重写）。 |
| 影视改编禁区 | **不得挪用任何知名影视/动画/音乐剧的专属表达**：迪士尼系角色造型、原创服装配色、专属台词、专属名场面构图（如《绿野仙踪》红宝石鞋）。凡印象来自"某部电影画面"而非"原著文字"，默认列为禁用，需中文化替换。 |
| 商标检查 | 个别公版角色名被注册为视听/形象商标（如部分童话形象）；不得把注册形象用作视频封面或标题主视觉。查不到就标注“风险低，标题用篇名不用形象名”。 |
| 公众人物 | 若改编关涉真实人物/商标品牌名，一律虚构化。 |

结论格式建议：`结论：通过 / 有条件通过（列禁用项）/ 不通过（建议更换作品）`。**不通过时必须主动建议目录中的替代作品**（见 `references/story-catalog.md`）。

同时提示用户：改编后成片享有**新的著作权**，这一步本身就是红利；不影响别人也改编同一篇公版作品。

## 三、五阶段工作流

### 阶段 1｜故事拆解 → `01_beats.md`
- 列出**节拍表**（beat list）：开端情境 → 目标 → 阻碍 → 关键反转（twist）→ 结局。
- 明确标出两类：
  - **不可变内核（必须保留）**：主题、反转机制、因果链、情感落点。例：《项链》的“借→丢→十年还债→得知是假货”。
  - **可变外壳（可整体替换）**：人名、地名、时代、职业、具体道具、饮食服饰、社交场景。
- 判断叙述视角与旁白空间（原作为第三人称还是第一人称，决定 TTS 旁白的口吻）。

### 阶段 2｜改编设计 → `02_adaptation.md`（核心差异化）

**第一步：先定改编分层，再产出。改编自由度四层，越往下越看不出改编痕迹：**

| 层 | 做法 | 识别度 |
|---|---|---|
| L1 替换 | 只换人名/地名/货币，情节照搬 | 一眼识破 |
| L2 场景置换 | 舞会→同学会，法郎→人民币 | 仍可识破 |
| L3 故事线重构 | 换道具、换事件、换人物关系，保留叙事“函数” | 需对比才认得出 |
| L4 主题迁移 | 只保留主题内核与结构公式，故事几乎全新创造 | 无人识破（“这故事好耳熟”） |

**默认目标 L3～L4**；用户明确要“蹭名篇流量/按篇名为检索词”时才退回 L2。

**第二步：提炼“结构公式”而非“映射表”。** 从原著抽出一个可重填的叙事函数，原封不动，然后把符号变量全部换掉。例《项链》公式：
> 渴望不属于自己的高光符号 → 借/虚/透支得到 → 短暂高光 → 意外失去 → 为体面补回去付出超额真实代价 → 漫长偿还 → 反转（当初的东西本就是假的/不值钱）→ 一生成空。

公式里的变量（符号、失去方式、偿还方式、反转机制）可任意替换；公式本身是唯一不可变项。产出 `02_adaptation.md` 时用这个骨架替代纯映射表：**公式 + 本次填进的具体符号 + 每处替换的动机**。

**L2 才用映射表**（保留给“明示改编”用途）：人名/场合/货币找当代等价替身，但内核一字不动；此类作品可加"改编自某某"标签蹭检索流量。

示例（莫泊桑《项链》→《一条项链》）：
- 玛蒂尔德 → 苏小蔓，小县城彩票站/商场收银员，爱面子；
- 路瓦栽先生 → 丈夫陈志远，县城中学老师，省吃俭用；
- 福雷斯蒂埃太太 → 高中同学林雅诗，嫁给地产商落户省城；
- 舞会 → 同学会晚宴；借“品牌项链”→ 借一条三四万的高仿“名贵项链”；
- 内核原样保留：弄丢 → 十年打工还债 → 老同学一句“那是A货”收尾。
- 一句改编立意（可用作脚本主题句）：*“她为一条项链还了十年债，最后发现那东西本来就不值得。”*

### 阶段 3｜剧本与设定 → `03_script.md` + `04_roles.md` + `05_scenes.md`
- **03_script.md**：中文分场剧本。每场写：地点/时间/人物动线/动作 + 台词/旁白。遵循 screenwriting 要点：**内心独白一律转成可见动作或台词**（“她攥紧衣角”而非“她觉得很丢脸”）；对话必须推进情节或揭示人物，删掉寒暄。
- **04_roles.md**：每个角色一张“护照”：中文名、一句话人设、发型/脸型/服装/道具/体态、性格关键词、**英文视觉描述段（供 gen_image 生成定妆图）**。多角色标注彼此关系与体型差异，避免 AI 混淆。
  - **年龄锚点（必写，生图后必抽检）**：护照里必须写死年龄数字，并加双向防御词——如“30岁，黑发无白发、无深皱纹，只是晒黑手糙”。凡是**同龄人关系**（发小/夫妻/同学/同龄对手）必须显式写“与 X 同龄 / same age”，否则模型会按“乡土/劳累/沧桑”等词自动画老 20 岁。生图后逐张抽检，年龄与设定不符即重做（定妆图是后续所有场景的视觉锚，错一张带歪一片）。
  - **人种/性别锚点（必写，生图后必抽检）**：所有角色的英文护照与场景 prompt 都要显式写 `East Asian Chinese faces (NOT Western/Caucasian)`；性别年龄必须写死（如 `56-year-old Chinese MALE teacher`）。模型在“教师/毕业/复古服饰”等语境下容易自动漂移成西方面孔或错性别。凡出现人物面孔的关键帧逐张抽检，人种/性别/年龄任一走样即重做。
  - **关键帧角色裁剪（必守）**：**每张关键帧只写该场实际出场角色的护照，禁止把全片角色描述整体复制进 prompt**——否则模型会在每张图里画出所有角色，导致人物提前出场（例：s01 本该无配角却画进主角）。对不该出现的角色加显式排除词（如 `NO delivery rider and NO elderly woman in this frame`）。生成后逐张核对“谁出场/谁没出场”是否与分镜一致。
- **05_scenes.md**：场景设定。每个主要场景写：中文描述、氛围、光线、标志性物件、**英文场景提示词**。固定画面的镜头（桌、墙、走廊）可复用 HTML 式一处生成多处。

### 阶段 4｜分镜 + 视频提示词 → `06_storyboard.md` + scenes.json
- 把剧本切成**≤12 秒的段**（agnes 硬上限），每段**一组主动作**，段间按**因果链**衔接（因为 A 所以 B）。
- 每段写：`id`（s01、s02…）、中文旁白/字幕（`zh`）、英文视频 prompt、首/尾关键帧或参考图标记。
- 英文 prompt **按 `agnes-video-director` 的六段式组装**：`[STYLE][PASSPORT][SCENE][TIME-CODES][SOUND][CONSTRAINTS]`；角色护照逐字复制进每段；每段至少一处环境反馈；结尾段留钩子。
- 分镜输出样式二选一不混用：时间戳式（`0:00-0:04`）或镜头命名式（`Shot 01 — 借项链`）。

### 阶段 5｜落地 + 文案 → scenes.json / keyframes / characters / `07_publish.md`
- 组装 `scenes.json`（结构见下文），关键构图用 `first_frame`/`last_frame` 锁定；跨场景一致性用角色定妆图进 `images`（reference 模式）。
- 生成目录：`characters/` 角色定妆图、`keyframes/` 各段首帧。
- **Gate 7（交付前必跑，不跳过）**：加载 `story-logic-check`，对 `01→06 + scenes.json + world-bible.md` 跑逻辑矛盾报告。结论必须为「通过」或「有条件通过（待确认项已逐一裁决）」，并把报告结论记入交付记录；不通过则先修稿再重跑。
- **07_publish.md**：标题公式（≥3 个备选）、封面文案、前 3 秒钩子句、标签启发。标题公式：`原著篇名 + 中国版` 或 `原著篇名 + 中文新编`，让“原著党搜索词”直接进标题；例：*「莫泊桑《项链》中国版：她借了一条高仿，还了十年债」*。
  - 封面：角色 + 关键词大字（用于抖音/视频号）；B站用争议性短句。
  - **发布文案含“原著改编自某某（公版作品）”标签**可提升信任与搜索权重。

## 四、叙事铁律（改编阶段每篇必查）

1. **开头 3 秒有视觉冲击或极端情境**：从冲突中段开场，不在背景交代上花前 10 秒。
2. **结尾卡在反转/悬念/高潮**：短剧单集尽量卡反转；单集短片允许留余韵，但必须有最后一拍的情绪标点。
3. **场景转化有承接线索**：相邻段之间用逻辑/声音/物件/情绪/悬念之一勾连，禁止硬切无承接。
4. **反转彩票**：欧·亨利式反转是这类内容的天然优势——反转句尽量放在**最后一段的结尾字幕**或最后一段旁白，制造“啊？”与重看率。
5. **情绪分段节流**：温情向放慢留白；嘲讽向台词密度提高；悬疑向每段给一个信息增量，不提前泄底。

---

## 五、旁白 / 字幕（TTS 适配）

- 每段 `zh` 文本 **25–45 个汉字**为宜（约 6–10 秒语速，适配 edge-tts `-15%` 节奏）。
- 按 agnes-media 的 TTS 规则：**整句分段合成，别逐短语**；避免制造机械感。
- 排版：字幕断句对应停顿；情绪句（反转、收束）单独成段。
- 若做多集：每集收束一处悬念钩子（“上集悬念”字段），供 next 集承接。

- [ ] 版权核查通过；译本/影视改编/商标禁用项已列出并避开
