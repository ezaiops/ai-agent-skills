# 模板测量与流水线笔记

实测基准：ffmpeg（Gyan 构建）、Windows PowerShell 5.1、素材为 NotebookLM / Gemini Notebook 导出的 mp4+srt。

## 两条已验证的模板

### 横版（1280×720 @ 24fps）

- 原 Gemini 水印包围盒：右下 `x=1157..1272, y=699..709`（约 115×11px，灰字）。
- 视频底边有约 3px 黑色边缘条（生成器自带），不影响。
- 水印标签：`142×34`，位置 `x = W - 146, y = H - 34`（右边缘留 4px，底边贴帧底；默认 `-LandscapeWatermarkOffsetY 0`，如需避开视频底部自带黑边，用负值上移，如 `-2`）。完全盖住原水印。
- 字幕样式基准：微软雅黑粗体 **40px/720p**，**黄色 &H0000E0FF（RGB #FFE000）**、黑边（outline 2.5，shadow 2），底边距 **14px**（贴底显示；长句居中不会压到右下角水印），Alignment=2（底部居中）；字号可用 `-SubtitleFontSize` 调整（如 `32`）。
- 片尾：白底 Gemini logo 约 2.8s，切换在第一帧全白处。实测横版样片 A：白帧起点 345.2s，最后一句字幕 344.36s 结束，截 345.0s，声音完整。

### 竖版（720×1280 @ 30fps）

- 原 Gemini 水印包围盒：`x=530..695, y=1237..1253`（约 165×16px），位于右下但离边缘有一段距离（右留 ~25px，下留 ~27px，含 8px 黑边）。
- 水印标签：`178×34`，位置 `x=522, y=1228`（右下留 20/18px 边距）。完全盖住。
- 竖版自带烧录字幕（多数无 SRT 或其 SRT 与视频不匹配），所以默认不烧字幕。
- 片尾实测竖版样片 C（白卡）：白帧起点 84.20s，最后一句语音结束于 83.76s（silencedetect），截 84.15s，正片收尾干净。

## 片尾自动检测算法

片尾模板不止一种：横版样片 A/B 是**白底** logo 卡（YAVG≈227），竖版样片 D 是**黑底** logo 卡（YAVG≈43-45，背景 #202124）。因此判据用"尾部连续片尾区"：

1. 回扫最后 `EndScanSeconds`（默认 15s），逐帧取 `YAVG` 与 `YMIN`（`signalstats,metadata=print:key=...:file=-`，两个 metadata 实例串联写 stdout）。
2. 帧分类为"片尾卡"：`YAVG ≥ 215`（白卡）或 `YAVG ≤ 58 且 YMIN ≥ 10`（黑卡，排除带纯黑的内容画面）。
3. 从最后一帧往前找连续的卡片帧，得到尾段起点；要求尾段时长 ≥0.8s。
4. 硬切保护：尾段起点前一帧与起点帧的 YAVG 阶跃须 ≥12（排除"视频本来就以暗场结尾"的误判）。
5. 截断点 = 起点前一帧；否则保留全片。
6. 安全保护：自动截断点早于总时长 60% 时保留全片并告警；可用 `-TrimSeconds` 手动强制。

实测：
- 横版样片 A（白卡）：起点 345.20s → 截 345.16s；语音结束 344.32s。
- 横版样片 B（白卡）：起点 360.50s → 截 360.47s；语音结束 359.86s。
- 竖版样片 C（白卡）：起点 84.20s → 截 84.16s；语音结束 83.76s。
- 竖版样片 D（黑卡）：起点 65.30s → 截 65.27s；语音结束 64.87s。
- 黑卡与暗场正片对比：暗场 YAVG=68、YMIN=5；黑卡 YAVG=43、YMIN=39，区分明显。

## SRT 配对与匹配

- 配对规则：同名 `.srt`，或 `<视频名> (transcribed ...).srt`（忽略大小写）。
- 匹配判断：`SRT 最后一句结束时间 / 视频时长 ∈ [0.85, 1.18]`，且仅横版烧录。
- 已知反例：某竖版样片的 SRT 与视频不匹配（SRT 结尾 101.58s，视频 87.26s，比值 1.164）。好在竖版一律不烧（`portrait → skip`），不受影响；若未来横版出现接近 1.18 的比值，额外核对 SRT 首句起点是否 ≤0.5s。
- 部分样片 SRT 为短句式（2~3s/条），部分为整段式（最长 ~23s/条）——本流水线对两种都做了断句处理。

## SRT → ASS 断句

- 按 Unicode 标点（`\p{P}`）切 token，合并至 ≤20 字（`MaxChars`），超 26 字（`HardSplit`）硬切。
- 每条的显示时长按文本长度（去掉标点）比例分配在原始时间窗内，单条最短 0.85s。
- 样式按视频高度等比缩放（720p 基准 40px / 底边距 14px），默认黄色 #FFE000（ASS `&H0000E0FF`）黑边。

## 水印生成

- 每个水印以 4x 分辨率绘制（System.Drawing），overlay 时 lanczos 缩回，边缘锐利。
- 圆角半径 ≈ 0.22×高，内描边 1.5~2px，文字字号 ≈ 0.44×高（粗体），文字过宽自动缩字号。
- **填充必须不透明（alpha 255）**：半透明时原水印会透出来（实测 alpha 150/236 皆透）。
- 风格：`beige`（底 #E7DDC7，字 #3A3125，边 #786446@110）；`dark`（底 #0E1016，白字，白边@46）。
- 选色原则：视频是暖米纸张质感 → beige 更协调（深色纯黑块观感不佳）。
- 水印文字不写入脚本，来自 `config.json` 或 `-WatermarkText` 参数（首次使用必须配置，见 SKILL.md）。

## 渲染参数

- `libx264` crf 18 / preset medium / yuv420p + aac 192k + faststart。
- 实测速度 ~350fps（两个模板均 10~25s 完成一条）。
- 滤镜用 `filter_complex_script` 文件 + `Push-Location` 临时目录规避 Windows 盘符冒号转义；输入输出路径走命令行参数（中文无碍）。

## 工作区

- 每次运行在 `%TEMP%` 建 `vc_xxxx` 目录，渲染完自动清理。
- 输出：`<视频目录>\成片\<原文件名>.mp4`（同名覆盖）。
- 批量时自动排除任何路径中含「成片」目录的视频，避免重复处理历史产物。

## 待办 / 潜在风险

- 换 NotebookLM 模板或分辨率后，水印与片尾位置需按上文方法重新量测（`Get-WatermarkLayout` 与 `Find-EndCardStart` 阈值）。
- 极亮场景（内容本身接近纯白）可能触发片尾误检——安全保护阈值 60% 已兜底，必要时用 `-TrimSeconds` 手动指定。
- 横版若出现"画面自带字幕 + SRT 匹配"的素材，会重复烧录，需人工用 `-Subtitles off`。
